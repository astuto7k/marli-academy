# Marli Teixeira Academy

Área de membros da Marli Teixeira Academy, com trilhas de formação em micropigmentação,
progresso por aluna, gamificação e materiais complementares.

## Desenvolvimento local

```sh
npm install
npm run dev
```

## Build de produção

```sh
npm run build
```

O projeto está preparado para publicação na Vercel.
